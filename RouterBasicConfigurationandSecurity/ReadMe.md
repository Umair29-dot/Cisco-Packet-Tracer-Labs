#### **Cisco Router Basic Configuration and Security Lab**



##### **Overview**

This lab focuses on the initial configuration and basic security of a Cisco router. The objective was to become familiar with Cisco IOS commands, device management, password security, and configuration storage.



##### **Network Topology**

1 Cisco 2901 Router (R1)

1 Cisco 2960 Switch (SW1)

3 PCs connected to the switch



##### **Objectives**

During this lab, I learned how to:

Access Cisco IOS command-line interface (CLI)

Change the router hostname

Configure secure passwords

Enable password encryption

Configure the privileged EXEC mode password

Understand the difference between running and startup configurations

Save configurations to non-volatile memory
