#### **Ethernet Packet Analysis and LAN Configuration Lab**



##### **Overview**

This lab focuses on Layer 2 communication, Ethernet frame forwarding, MAC address table learning, and the Address Resolution Protocol (ARP).



##### **Network Topology**



2 Cisco 2960 Switches

2 PCs

2 Laptops

Switch-to-switch connection

End devices connected through Ethernet links



##### **Objectives**

Configure a basic LAN environment

Understand Ethernet frame transmission

Analyze MAC address table learning

Observe ARP request and ARP reply processes

Verify end-to-end connectivity

Configure and secure network devices with encrypted passwords
