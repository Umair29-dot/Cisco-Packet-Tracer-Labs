#### **Network Routing and Subnetting Lab**



##### **Overview**

This lab focuses on Layer 2 and layer 3 communication, IP addressing, subnetting, switching, and routing using Cisco Packet Tracer.



##### **Network Topology**

1 Cisco Router (2911)

Multiple Switches

PCs, Laptop, and Printer

Three separate LANs connected through router interfaces



##### **Objectives**

Router configuration

Switch connectivity

IPv4 addressing

Subnetting calculations

Default gateway configuration

LAN routing

Network troubleshooting
